# Skab Evidence Pages v0.1 — Added Pages Only

## Purpose

This package adds a standalone `/evidence/` section to the Skab Digital Reality Arcade repository.

It does **not** replace or modify the root `index.html`, existing game pages, `404.html`, or existing README.

## Drop-In Structure

Copy the full `evidence/` folder into the repository root.

Expected route after upload:

```text
https://skabkleveta-creator.github.io/skab-digital-reality-arcade/evidence/
```

Each game evidence page follows:

```text
/evidence/<game-title-folder>/index.html
```

## Approval Rule

All evidence pages are marked draft / pending Ken approval. They are structured pages, not final claims.

Recommended workflow:

```text
Draft Evidence → Ken Review → Correct Wording / Artifacts → Approve → Publish
```

## Scope Lock

This package is for testing only added pages. Do not merge any homepage navigation changes until the Evidence landing page is reviewed.
