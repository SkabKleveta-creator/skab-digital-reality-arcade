What it is

TRACE CHAIN is a decision-board proof where the player balances mission speed, control discipline, documentation, validation debt, findings, remediation, and after-action learning before a green status lies.

Current status

v0.2.2 Weekend Lock is the current named baseline. This page is a deployable index so the Arcade card loads something useful while the full board file is staged or rebuilt.

What it proves

Decision-board play can model audit pressure without pretending a clean dashboard equals validated truth.

Still unproven

Whether a first-time player can run one clean round without a facilitator and still produce a useful AAR.

Quick Run Structure

1. Mission pressure: The player receives a control/audit situation with speed pressure and incomplete visibility.
2. Evidence choice: The player chooses whether to verify, document, defer, or push forward.
3. Control consequence: Weak evidence creates validation debt; strong evidence costs time but improves traceability.
4. Finding / CAP path: Bad assumptions become findings; disciplined recovery becomes a CAP or corrective action.
5. AAR: The run ends by explaining what was proven, what remained unproven, and what would be changed next.
