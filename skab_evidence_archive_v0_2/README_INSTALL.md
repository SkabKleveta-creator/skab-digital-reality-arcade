# Skab Evidence Archive v0.2

Fresh added-pages package for the Skab Digital Reality Arcade.

## Install

Copy the `/evidence/` folder into the repository root.

Final clean URL:

`https://skabkleveta-creator.github.io/skab-digital-reality-arcade/evidence/`

## Do not overwrite

Do not overwrite:
- root `index.html`
- root `README.md`
- root `404.html`
- `/games/`
- `/.github/`

## Optional homepage access

`OPTIONAL_ROOT_INDEX_EASTER_EGG_PATCH_NOT_APPLIED.md` contains the optional homepage Easter egg code. It is not applied in this package.
